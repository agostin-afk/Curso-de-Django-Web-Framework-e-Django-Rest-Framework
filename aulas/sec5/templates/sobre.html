Sobre - Recipes

O que é Recipes?

Recipes é uma aplicação web desenvolvida com Django para compartilhar e descobrir receitas culinárias.

Objetivo

Nosso objetivo é criar uma comunidade de cozinheiros amadores e profissionais que compartilham suas receitas favoritas.

Tecnologia

Esta aplicação foi desenvolvida utilizando Django Web Framework e segue as melhores práticas de desenvolvimento web.
